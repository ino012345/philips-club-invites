# Philips Club — Invites

Philips Club が開催するイベントごとの招待ページを管理するリポジトリです。

## ディレクトリ構成

各イベントは `YYYY-MM-<slug>/` の形式でディレクトリを切り、`index.html` を配置します。

```
philips-club-invites/
├── 2026-08-party/      # Party — The Inaugural Edition（2026年8月2日）
│   └── index.html
└── ...
```

## イベント一覧

| ディレクトリ | イベント名 | 日程 | 会場 |
|---|---|---|---|
| [2026-08-party](./2026-08-party/) | Party — The Inaugural Edition | 2026年8月2日（日） | リビエラ逗子マリーナ |

## ページの公開

各 `index.html` は単体で動作するスタンドアロン HTML です。
GitHub Pages や任意のホスティングサービスで公開できます。
